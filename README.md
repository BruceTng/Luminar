# Luminar

Projeto de estudo criado para praticar e consolidar HTML, CSS e JavaScript "puro" (sem frameworks).

Este não é um projeto profissional. É um site fictício de energia solar/limpa feito com fins de aprendizado. Não representa uma empresa real e não deve ser usado como referência de produção.

## Objetivo

Este repositório foi feito para treinar:

- Estruturação semântica de páginas em HTML5
- Layout responsivo com CSS (Flexbox, Grid, media queries)
- Interatividade básica com JavaScript
- Organização de um projeto front-end (pastas, assets, boas práticas)

## O que tem no site

Uma landing page fictícia de uma marca de energia solar, com:

- Header fixo com navegação
- Seção hero com dados/estatísticas
- Cards explicando fontes de energia renovável
- Vitrine de produtos
- FAQ (perguntas frequentes) com `<details>`/`<summary>`
- Formulário de contato/orçamento
- Footer

## Linguagens

- HTML5

- JavaScript (Vanilla)

## Como rodar

Não precisa de nada instalado — é só HTML/CSS/JS puro.

1. Clone o repositório:
```bash
   git clone https://github.com/seu-usuario/luminar.git
```
2. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server no VS Code).
